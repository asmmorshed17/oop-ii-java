# 🧩 Mini Projects (OOP in Java)

## 📌 Overview

This repository contains **8 Object-Oriented Programming mini projects in Java**, designed to demonstrate real-world system modeling using core OOP principles.

These projects focus on:

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction (Interfaces)
* Exception Handling
* Aggregation & Composition
* Collections Framework (ArrayList)

---

# 📚 Projects Included

---

## 🏥 1. Hospital Management System

**Concepts:** Inheritance, Aggregation, Encapsulation, Exception Handling, ArrayList

* Doctor, Patient, Nurse management
* Appointment scheduling with conflict checking
* Prescription and billing system
* `HospitalManager` aggregates all entities using `ArrayList`

---

## 💳 2. Payment Gateway System

**Concepts:** Interface, Polymorphism, Exception Handling, Composition

* Multiple payment methods (CreditCard, DebitCard, PayPal)
* Transaction processing (authorize → capture → refund)
* Strong composition between PaymentService and payment objects

---

## 🏠 3. Smart Home Automation System

**Concepts:** Interface, Abstraction, Polymorphism, Aggregation, ArrayList

* Smart devices: Light, Fan, Thermostat, DoorLock
* Central controller (SmartHub) manages all devices
* Devices stored using `ArrayList<Device>` (aggregation)

---

## 🎓 4. University Course Management System

**Concepts:** Inheritance, Polymorphism, Encapsulation, Composition

* Online and Offline courses
* Assignment submission rules vary per course type
* Grade protection (encapsulation)
* Course contains Assignment objects (composition)

---

## 🛒 5. E-commerce Shopping Cart System

**Concepts:** Inheritance, Polymorphism, Exception Handling, ArrayList, Aggregation

* Product categories: Electronics, Clothing, Grocery
* Shopping cart uses `ArrayList<Product>`
* Order generation and invoice system
* Stock validation with exceptions

---

## 🚗 6. Car Rental System

**Concepts:** Interface, Inheritance, Polymorphism, Composition, ArrayList

* Vehicles: Car, Bike, Truck
* Rent calculation varies per vehicle
* RentalAgreement uses vehicle (composition)
* Multiple rentals stored in collections

---

## 🏦 7. Banking Application

**Concepts:** Encapsulation, Inheritance, Exception Handling, Aggregation

* Account types: Savings, Current
* Deposit, withdraw, transfer operations
* Customer aggregates Account
* Secure balance using encapsulation

---

## 🎮 8. Simple 2D Game System

**Concepts:** Inheritance, Polymorphism, Encapsulation, Composition

* Characters: Player, Enemy, Boss
* Weapon and PowerUp modify behavior
* Strong encapsulation of health and level
* Game entities interact via composition

---

# 🧠 Key OOP Concepts Demonstrated

## 🔹 Encapsulation

* Private data with controlled access (e.g., balance, health)

## 🔹 Inheritance

* Base classes extended by specialized classes

## 🔹 Polymorphism

* Same method behaves differently across classes

## 🔹 Interface / Abstraction

* Common contracts for system behavior

## 🔹 Aggregation

* “Has-a” relationship (e.g., Manager has List of objects)

## 🔹 Composition

* Strong ownership (e.g., Order contains Products)

## 🔹 ArrayList Usage

* Dynamic storage for collections of objects
