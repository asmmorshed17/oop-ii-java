# 🏦 Banking Application (OOP)

## 📌 Problem Statement

1. Banking Application
   Concepts: Encapsulation, Inheritance, Exception Handling

Goals
• Secure balance through getters/setters; different interest/fees by account type.

Scope
• Account → SavingsAccount, CurrentAccount.
• deposit, withdraw, transfer.
• Exceptions: InsufficientFundsException, NegativeAmountException.

Classes:
• Account (base) → SavingsAccount, CurrentAccount
• Transaction, Customer

Features:
• Use getters/setters to secure balance details.
• Handle exceptions like InsufficientFundsException.
• Demonstrate inheritance for account types with unique interest calculations.

---

## 📖 Description

This project implements a Banking Application using Object-Oriented Programming in Java.
It simulates basic banking operations such as deposit, withdrawal, and fund transfer with proper error handling.
