# 🎮 Simple 2D Game (OOP)

## 📌 Problem Statement

1. Simple 2D Game (OO)
   Concepts: Polymorphism, Inheritance, Encapsulation

Goals
• Characters share base behaviors; attacks differ polymorphically.

Scope
• Character base → Player, Enemy, Boss.
• Weapon, PowerUp modify damage/time.
• Encapsulate health, level with controlled mutation.

Classes:
• Character (base) → Player, Enemy, Boss
• Weapon, PowerUp

Features:
• Use polymorphism for attack styles.
• Encapsulate player stats (health, level).
• Inherit movement and combat behavior.

---

## 📖 Description

This project implements a Simple 2D Game system using Object-Oriented Programming in Java.
It demonstrates character interaction, combat behavior, and game mechanics using core OOP principles.
